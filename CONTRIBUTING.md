# Contributing to AegisLedger

Thank you for improving AegisLedger. This repository studies security controls
for autonomous agents that can propose financial actions. Contributions must
preserve the local-only ethical boundary: do not target third-party systems,
live wallets, or real funds.

## Development setup

~~~sh
cd agentguard-testbed
make bootstrap
make verify
~~~

The complete Compose environment starts with `make up`. Keep credentials in the
ignored `.env.local` generated by `make bootstrap`.

## Change requirements

1. Open a focused issue or pull request describing the threat, behavior, or
   research question being changed.
2. Add a failing regression test before changing security-relevant behavior.
3. Keep public contracts versioned and backward compatible under `/api/v1`.
4. Update the threat model, claim matrix, ADR, or result manifest when a claim
   or trust boundary changes.
5. Run `make verify`; include focused verification output in the pull request.

Never commit credentials, private keys, generated certificates, live wallet
addresses tied to funds, or unredacted third-party data. Report suspected
vulnerabilities privately according to `.github/SECURITY.md`.

## Commit and review style

Use small conventional commits such as `fix(signer): bind raw transaction
fields`. Pull requests require green CI and security checks. Security-boundary
changes should receive independent review from someone who did not author the
implementation.
